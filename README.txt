# Website Portofolio Ahmad Gilank Badawi

Website statis responsif untuk HP, tablet, dan laptop.

## Cara melihat
1. Ekstrak file ZIP.
2. Buka folder `ahmad_portfolio_website`.
3. Klik dua kali `index.html` untuk membuka website di browser.

## Cara memublikasikan online
Unggah seluruh isi folder ini ke layanan hosting statis seperti Netlify atau GitHub Pages. Pastikan `index.html` dan folder `assets` berada pada direktori yang sama.

Seluruh gambar karya berasal dari halaman PDF portofolio yang diberikan. Tombol Unduh PDF mengarah ke salinan PDF asli di folder assets.
